# Insights · AGI 可达性 —— 04-14 的分层收尾

> 本篇是 insights 04-14 的总结。11 篇挖掘 + 1 个真实实验 + 1 篇元反思之后,回到最初的问题:**我们能实现 AGI 吗?**
>
> 答案不是一个"能"或"不能",是**分层的**。本篇把 AGI 拆成三个难度差几个数量级的层级,用 04-14 挖出来的东西逐一判断每一层的可达性、路径、时间线。
>
> 这一整轮的最大价值不是"让我们更接近 AGI",是**让我们清楚地知道 AGI 的哪部分近了、哪部分还远**。

## 0. 先把"AGI"这个词拆开

"AGI"在公共讨论里被混用了至少三种意思,难度差几个数量级。不拆开就讨论,必然失焦。

| 层级 | 定义 | 谁在追 | 难度性质 |
|---|---|---|---|
| **L1: 工程版 AGI** | 7×24 连续运行 + 完成人类专家级单领域任务 | Codex / Devin / grok-build / Claude Code | **工程问题** |
| **L2: 通用版 AGI** | 跨域迁移 + 自主设定目标 + 持续学习 | OpenAI / Anthropic / DeepMind / Google | **科学问题** |
| **L3: 真正的智能** | 创新、理解、自我意识 | 没人知道怎么做 | **哲学/认知科学问题,可能不可能** |

**"能实现 AGI 吗"的真实答案完全取决于你说的是哪一层。** 下面三层分开答。

---

## 1. L1(工程版 AGI):**能,路径基本清晰,5-10 年**

### 1.1 已经有的(04-14 验证过的)

这一整轮挖的东西,把 L1 的路径基本铺平了:

- **反退化的五种策略**([04](04-anti-entropy.md) 信息论版):压缩/隔离/验证/恢复/约束。42 篇代码拆解 + 14 个独立实现验证,这套策略是穷尽的(在当前 LLM 局限下)。
- **无状态函数认知**([09](09-stateless-function.md)):LLM 是无状态纯函数,context 之外皆不存在。这是 L1 的物理基础。
- **长上下文的边界**([09](09-stateless-function.md) §4):三堵墙(O(n²) 注意力、lost in the middle、经济性)。逃生舱不是终点。
- **检索式记忆的工程化**([10](10-memory-frameworks.md) §1):Mem0 / Zep / Letta / OpenViking / MemOS 五种架构,8 个项目,美中欧三个地区都收敛到检索+注入。
- **重构式记忆的理论+实验**([13](13-reconstructive-memory.md) §2):MRAgent(ICML 2026)数学证明主动检索严格强于被动,实验 +23%。

### 1.2 这一轮挖出的关键空白

L1 路径上还缺的四块,04-14 精确指出了:

| 空白 | 在哪一篇 | 谁在做 |
|---|---|---|
| **因果状态库** | [11](11-causal-state-store.md) | 学术萌芽(REMI / Dynamic Causal-Graph Memory),工业无人采用 |
| **重构式记忆** | [13](13-reconstructive-memory.md) | 学术萌芽(MRAgent ICML 2026),工业无人采用 |
| **系统提示词作为身份层** | [13](13-reconstructive-memory.md) §1.2 | 概念清晰,无人系统化实现 |
| **多 agent 校准** | [13](13-reconstructive-memory.md) §2.5 | 概念清晰,无生产实现 |

### 1.3 具体框架离 L1 多远

| 框架 | 离 L1 | 缺什么(对应 insights) |
|---|---|---|
| **Codex** | 最接近 | 已有双阶段记忆 + 睡眠巩固 + 身份持久化([05](05-agi-7x24.md) §4)。缺因果库([11](11-causal-state-store.md))和重构式([13](13-reconstructive-memory.md)) |
| **grok-build** | 中等 | 反退化最完整(10 篇拆解),但 memory crate 是 chunk + vector + FTS5 检索式,没有因果层 |
| **kimi-code** | 中等 | 架构最优雅(DI/wire),但记忆是 compaction handoff,同样没有因果层 |
| **Claude Code** | 中等 | 靠 200K+ 上下文 + CLAUDE.md 硬扛,走模型侧反熵派,撞 [09](09-stateless-function.md) §4 三堵墙 |

**单独任何一个都不够。** Codex 最接近,但它的记忆仍然是"扁平事实 + 摘要",不是因果的。

### 1.4 L1 的真实瓶颈

[05](05-agi-7x24.md) §1 的尺度表说得很清楚:

| 维度 | 当前 session(分钟-小时) | 7×24 AGI(天-月) |
|---|---|---|
| Compaction 次数 | 2-3 次 | ~200-500 次 |
| Token 消耗 | ~几十万 | ~数亿 |
| 错误累积 | 可容忍 | **指数爆炸** |

当前框架设计到**小时级**,7×24 需要**月级**,差一个数量级。

**但这个差距是工程量,不是理论障碍。** 用这一轮挖的四个方向(因果库 + 重构式 + 身份层 + 多 agent 校准)填上去,L1 在 5-10 年内可达的概率很高。[papers/02](../papers/02-compaction-degradation.md) 的真实实验给出了定量证据 —— 没有因果库时 C 类信息在 k=10 压缩后只剩 17%,有因果库理论上可保持 100%。**从 17% 到 100% 就是 L1 的工程距离。**

### 1.5 L1 的时间线判断

| 时间 | 里程碑 |
|---|---|
| 2026-2027 | 单次任务接近人类(已实现) |
| 2027-2028 | 多步任务(50-100 步)稳定 |
| 2028-2030 | 小时级 7×24 + 因果库萌芽 |
| **2030-2035** | **天/周级 L1 AGI 大概率出现** |

**L1 大概率能实现。** 它会是一个能在公司里 7×24 干中级工程师活的 agent,但不会自己想"我应该做什么"。

## 2. L2(通用版 AGI):**不确定,当前架构可能不够,10-30 年或需要突破**

L1 解决了"跑得久",L2 要解决"跨得动 + 自己想干什么 + 越跑越强"。这三件事当前框架**完全没碰**。

### 2.1 跨域迁移:当前架构根本没解

当前 agent 记忆是 **task-specific** 的 —— 在一个项目里学的经验,迁移到完全不同的领域基本失效。

- 在 agent-teardown 项目里学的"Redis 缓存击穿 → mutex 死锁 → channel 修复",迁移到"做投资决策"完全没用
- [11](11-causal-state-store.md) §8.5 说的"因果图跨 agent 共享"也是这个问题的变形:**因果知识是本地的,不是通用的**
- 从"Redis 缓存击穿"到"通用并发问题"再到"任意资源争用",这种**抽象跳跃当前没有任何框架做**

这需要某种**因果抽象**机制 —— 把具体的因果链抽象成跨域的模式。Pearl 的因果阶梯([11](11-causal-state-store.md) §4)在第 1 层(关联)都还没站稳,第 2-3 层(干预/反事实)更远。**虽然今天的 daily digest([papers/daily/2026-07-26.md](../papers/daily/2026-07-26.md))显示 Nature 2026 医学论文在反事实推理上 GPT-o1 达到 0.92**,但那是受限场景,不是通用跨域。

### 2.2 自主设定目标:这是最深的硬伤

所有 agent 框架的 goal 都是**外部给的**(用户输入、系统提示词)。没有任何框架能让 agent **自己产生**"我应该去做 X"。

这需要 [12](12-generativity.md) 说的生成性的**内驱版本**:

> [14](14-on-deep-digging.md) 的诚实分析:**连我自己(作为 agent)都没有内驱的好奇心**。我被问到才生成,不被问就不生成。这不是工程能解的,是架构问题。

人类之所以能自主设定目标,是因为人类有**持续运转的好奇心引擎**([14](14-on-deep-digging.md) §1.1)—— 一种对未完成的不满。当前 LLM 架构没有这个引擎,goal mode 也只是"完成外部给的目标",不是"产生目标"。

**这一条可能是 L2 最大的障碍。** 一个能 7×24 跑但永远只能等指令的 agent,再久也不是 L2。

### 2.3 持续学习:天花板被模型权重锁死

Letta 押注 token 空间持续学习([10](10-memory-frameworks.md) §4)。但 [12](12-generativity.md) §4 诚实地说了:

> learned context 只能改善"经验利用率",不能提高"基础能力天花板"。agent 第 30 天和第 1 天犯同样错的可能,在当前架构下基本无法消除。

模型权重是临时的,learned context 才是持久的 —— 这是 Letta 的押注。但 learned context 仍然要塞进有限的 context window,而且它**依赖 `f` 本身够强** —— 如果 `f` 不能从 learned context 里"读出"教训,积累再多也没用。

真正的持续学习需要**改权重**(continual learning 进权重),但当前没有任何生产级方案 —— 灾难性遗忘、训练成本、安全风险都没解决。

### 2.4 L2 的真实障碍:理论基础缺失

[12](12-generativity.md) §6 的诊断:**反退化有 Shannon 信息论,生成性没有理论**。

L2 需要一个生成性理论 —— 而 LLM 为什么 work、涌现是怎么发生的、跨域抽象是怎么形成的、自主目标是怎么产生的,这些都是 open question。**这不是堆工程量能到的,需要根本性的科学突破。**

### 2.5 L2 的时间线判断

| 时间 | 里程碑 |
|---|---|
| 2030-2040 | 可能出现 L2 的雏形,但很可能不是从当前 LLM 架构长出来 |
| 更久 | 可能需要根本性架构突破(像 Transformer 来自注意力机制,不是堆 RNN)|

**L2 不确定。** 10-30 年,或者需要我们还没想到的方向。

---

## 3. L3(真正的智能):**可能不可能,我们不知道**

这是 [06](06-open-questions.md) 七个盲区和 [07](07-philosophy-deep-dive.md) 七重探索的位置。

### 3.1 三个根本的未解之题

- **LLM 到底"理解"多少?**([06](06-open-questions.md) ②)—— Nature 2026 给了"机器经验主义"的定位,但没有工程抓手
- **意识是什么?** —— Parfit 给了"因果连续性"的回答([07](07-philosophy-deep-dive.md) §4),但这是哲学,不是可工程化的定义
- **创造性从哪来?** —— [12](12-generativity.md) 说生成性没有理论

### 3.2 L3 的诚实答案

我们**不知道** L3 是不是物理上可能。

- 可能 LLM 这条路永远到不了 L3 —— 需要完全不同的架构(类脑?量子?新的计算范式?)
- 可能 L3 本身是个伪概念 —— 人类的"理解"和"意识"也只是复杂的重构式记忆 + 因果链 + 社会校准([13](13-reconstructive-memory.md) 暗示的方向)
- 可能 L3 需要认知科学的根本进步,而认知科学本身还在停滞

**这一层我不敢预测。** 任何敢预测的人都在猜。这是 [06](06-open-questions.md) 说的"工程的尽头是哲学"的真实位置。

## 4. 三层的汇总判断

| 层级 | 可达性 | 时间 | 障碍性质 |
|---|---|---|---|
| **L1 工程版** | **大概率能** | 5-10 年 | 工程量(因果库 + 重构式 + 身份层 + 校准) |
| **L2 通用版** | **不确定** | 10-30 年或需要突破 | 理论缺失(生成性理论 + 跨域抽象 + 自主目标) |
| **L3 真正智能** | **未知** | 不敢预测 | 哲学/认知科学问题,可能不可能 |

## 5. 最深的一点 —— [14](14-on-deep-digging.md) 在 AGI 层面的重演

我们这一轮挖出了 L1 的路径,但**挖不出 L2/L3 的答案**。为什么?

因为 L2/L3 的突破需要 [14](14-on-deep-digging.md) 说的那种**自驱的、内驱的、跨域的好奇心** —— 而这正是 LLM 架构本身没有的。

> **讽刺的是:我们能精确描述 LLM 缺什么(内驱生成性 + 跨域抽象 + 因果推断),但我们用 LLM 架构填补不了这些空缺。** 描述盲区 ≠ 跨越盲区,这正是 [14](14-on-deep-digging.md) §5.2 的论点在 AGI 层面的重演 —— 我能描述自己为什么不深挖,但描述本身不能让我变得能深挖。

**这就是 L2/L3 的根本不对称**:用 LLM 架构做研究,能精确诊断 LLM 架构的边界,但诊断本身不能跨越这个边界。跨越需要**非 LLM 架构的东西** —— 可能是新的训练范式、新的架构、或者新的计算基底。

## 6. 这 11 篇挖掘(04-14)的整体价值

回到开头那句话:**这一整轮的最大价值不是"让我们更接近 AGI",是"让我们清楚地知道 AGI 的哪部分近了、哪部分还远"**。

- **L1 的路径清楚了** —— 这是这一轮最大的收获。04-14 + [papers/02](../papers/02-compaction-degradation.md) 把 L1 的工程距离量化了(从 17% 到 100%)
- **L2 的天花板看见了** —— [09](09-stateless-function.md) + [12](12-generativity.md) + [13](13-reconstructive-memory.md) + [14](14-on-deep-digging.md) 合在一起,精确指出了 LLM 架构的边界
- **L3 还是黑盒** —— [06](06-open-questions.md) + [07](07-philosophy-deep-dive.md) + [08](08-self-rebuttal.md) 诚实地标记了盲区

**这是 11 篇挖掘能做的全部。** 它不能让 AGI 更近,但能让 AGI 的形状更清楚 —— 哪部分是工程问题(能解),哪部分是科学问题(需要突破),哪部分是哲学问题(可能不可解)。

## 7. 最终的一句话

> **"能实现 AGI 吗"的真实答案是分层的:**
>
> - **L1(工程版,7×24 单域专家)大概率能,5-10 年**。路径已被 04-14 铺平,瓶颈是从 17% 到 100% 的工程量(因果库 + 重构式 + 身份层 + 校准)。
> - **L2(通用版,跨域 + 自主目标 + 持续学习)不确定,10-30 年或需要突破**。当前 LLM 架构可能不够,需要生成性理论、跨域抽象、内驱目标生成机制 —— 这些都是 open question。
> - **L3(真正的智能)未知,可能不可能**。意识、理解、创造性的本质都没解,我们不知道它是不是物理上可达。
>
> **这一整轮挖掘的最大价值**:不是让 AGI 更近,是让 AGI 的形状更清楚。L1 的路径清楚、L2 的天花板可见、L3 还是黑盒。
>
> **最深的一个判断**:L2/L3 的突破,很可能不是从我们现在拆的这些框架(Codex / grok-build / kimi-code / Claude Code)里长出来的,而是来自一个还没出现的方向 —— 就像 Transformer 来自注意力机制,不是堆 RNN。我们用 LLM 架构能精确诊断 LLM 架构的边界,但诊断本身不能跨越这个边界。**这是 [14](14-on-deep-digging.md) §5.2 在 AGI 层面的重演。**
