## 🔥 必须深挖(4 条)

### 🔥-1 · Memora Benchmark：FAMA 指标——惩罚"使用过期记忆"

- **来源**：arXiv:2604.20006 · "From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents"
- **主题**：⑤ benchmark ① Agent 记忆 ④ 重构式vs检索式
- **核心**：Memora 引入了 **Forgetting-Aware Memory Accuracy (FAMA)**——不仅检查答案是否包含正确信息，还**惩罚使用过期/已失效记忆**。实验发现：标准指标高估了长期记忆性能，FAMA 惩罚后排名变化显著（如 Nemori 因 forgetting reduction 小而从落后变领先）。三大任务维度：remembering / recommending / reasoning。时间维度从 weekly → monthly → quarterly 渐进退化。
- **对项目的含义**：
  - **FAMA 指标直接验证了 causal-memory 的 prevented/superseded 设计**——prevented 负扩散自动抑制过期记忆，superseded 标记确保旧信息不被误用
  - **Memora 是比 LoCoMo/LongMemEval 更难的 benchmark**——它测"该忘的忘了没有"，不只是"该记的记了没有"
  - 应该在 Memora 上评估 causal-memory
- **是否值得深挖**：🔥 **必须**

### 🔥-2 · Mem0 2026 状态报告：LongMemEval 94.4%，LoCoMo 92.5%

- **来源**：mem0.ai/blog/state-of-ai-agent-memory-2026
- **主题**：⑤ benchmark ① Agent 记忆
- **核心**：Mem0 发布了 2026 年状态报告，报告了大幅提升的数字：
  - LongMemEval **94.4%**（~6,787 tokens/query）
  - LoCoMo **92.5%**（~6,956 tokens/query）
  - BEAM 1M **64.1%**，BEAM 10M **48.6%**
  - 新算法："single-pass ADD-only extraction"——把 agent 生成的事实当作一等公民
  - 记忆过时（staleness）被列为未解决问题
- **对项目的含义**：
  - **Mem0 在 LongMemEval 上从 ~49% 跳到 94.4%**——我们 71.2% 的差距大幅拉大
  - 但 Mem0 的改进是"更好的事实提取"，不是因果推理——**它在测的维度和我们不同**
  - Mem0 自己承认"记忆过时"是未解决问题——这正是 causal-memory 的 prevented/superseded 解决的
- **是否值得深挖**：🔥 **必须**

### 🔥-3 · ARIS：自动科研 Agent 的"因果学习闭环"

- **来源**：github.com/wanshuiyin/auto-claude-code-research-in-sleep (ARIS) · arXiv:2605.03042
- **主题**：③ 7×24 ⑦ 持续学习 ② 因果推理
- **核心**：ARIS 是一个自动科研 Agent，有一个"Research Wiki"持久记忆——记录每次实验的因果结果：
  ```
  Round 1: read papers → wiki → idea A → FAIL → wiki records "A fails because OOM"
  Round 2: read wiki → sees A failed → idea D → PARTIAL → wiki records "D works on small models"
  Round 3: read wiki → knows A+D → idea F → SUCCESS
  ```
  这是一个**因果记忆防止重复犯错的实例**——和 causal-memory 的 trap-world ablation 实验完全对应。
- **对项目的含义**：
  - ARIS 的 wiki 是因果记忆的简化版——它记录"X failed because Y"，正是 caused/prevented 边
  - ARIS 的三轮实验展示了 causal-memory 的 Condition C（0% 重复犯错）在实际科研场景中的价值
  - 可以引用 ARIS 作为 causal-memory 的使用场景验证
- **是否值得深挖**：🔥 **必须**
