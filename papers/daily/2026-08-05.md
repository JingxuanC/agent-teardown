## 🔥 必须深挖(4 条)

### 🔥-1 · MAGMA：多图记忆架构（ACL 2026 Main）— causal graph 的学术竞争者

- **来源**：arXiv:2601.03236 · "MAGMA: A Multi-Graph based Agentic Memory Architecture for AI Agents" · ACL 2026 Main
- **主题**：① Agent 记忆 ② 因果推理 ⑤ benchmark
- **核心**：MAGMA 将记忆拆成四张正交图：semantic / temporal / causal / entity。检索是"policy-guided traversal"——按 query 类型路由到不同图。在 LoCoMo 和 LongMemEval 上"consistently outperforms state-of-the-art"。LoCoMo LLM-judge score 达到 **0.70**。
- **和 causal-memory 的关系**：
  - ✅ MAGMA 有 **causal graph**——和我们的 caused/enabled/prevented edges 直接重叠
  - ✅ 分图设计（semantic/temporal/causal/entity）vs 我们的统一图（7 种 typed edge 在一张图上）——这是**架构哲学分歧**
  - ❌ MAGMA 的 causal graph 没有负扩散（prevented 的 -0.3 spreading）
  - ❌ 没有 intervention_query（前向模拟）
- **对项目的含义**：MAGMA 是第一个把 causal 作为一个独立记忆维度的 ACL Main 论文。它验证了我们的方向（causal 是一等公民），但它的"分图"设计和我们的"统一图"是正面对抗。需要在论文中精确对比。
- **是否值得深挖**：🔥 **必须**

### 🔥-2 · MemPalace：96.6% R@5 但被审计发现是 verbatim 的功劳

- **来源**：github.com/MemPalace/mempalace (47K stars) + arXiv:2604.21284 (批判性分析)
- **主题**：① Agent 记忆 ⑤ benchmark ④ 重构式vs检索式
- **核心**：MemPalace 声称 LongMemEval 96.6% R@5，零 LLM 调用。但独立审计（arXiv:2604.21284 + GitHub issue #27）发现：这个分数来自 **ChromaDB 默认 embedding + verbatim 全文存储**，MemPalace 的"宫殿"结构（wings/rooms/halls）没有参与。审计称之为"misleading attribution"。
- **对项目的含义**：
  - **verbatim storage 是有效的**——LazyMem 和 MemPalace 都证明了"不提取、只存原文"比"LLM 提取"效果更好。这验证了 causal-memory 的 session_logs 设计
  - **96.6% 是检索 recall，不是回答准确率**——R@5 衡量"能不能找到包含答案的 chunk"，不衡量"能不能正确回答问题"。我们的 71.2% 是 LLM-judge accuracy，更高难
  - **Mem0 追上来了**——审计提到 Mem0 2026 年 4 月的 "token-efficient memory algorithm" 把 LongMemEval 提到了 93.4%
- **是否值得深挖**：🔥 **必须**

### 🔥-3 · Graph-Native Cognitive Memory：belief revision + URI addressing

- **来源**：arXiv:2603.17244 · "Graph-Native Cognitive Memory for AI Agents"
- **主题**：① Agent 记忆 ② 因果推理 ③ 7×24
- **核心**：一个单图架构（Neo4j + Redis），所有关系统一在一张 property graph 里——和 causal-memory 的设计哲学一致（统一图 vs MAGMA 的分图）。关键创新：
  1. **Belief revision semantics**——形式化的信念修正（AGM 公理），比 Oracle 的 reversible consolidation 更理论化
  2. **URI addressing**——记忆节点有确定性 URI，支持跨系统引用
  3. **Immutable revisions + mutable tag pointers**——版本控制式记忆管理
  4. 论文明确对比 MAGMA："MAGMA disentangles into separate graphs, whereas our architecture unifies all relationships in a single property graph with typed edges, enabling cross-dimensional traversal"——**这几乎是在说我们的设计哲学**
- **对项目的含义**：
  - 这篇论文为**统一图 vs 分图**的架构辩论提供了学术支撑——它站在统一图这边（和我们一样）
  - Belief revision semantics 值得学习——比我们的 invalidate_superseded 更形式化
  - URI addressing 可以考虑加入 causal-memory
- **是否值得深挖**：🔥 **必须**

### 🔥-4 · "From Experience to Strategy"：可训练图记忆 + RL 权重优化

- **来源**：arXiv:2511.07800 · Xia et al. · 19 citations
- **主题**：① Agent 记忆 ⑦ 持续学习
- **核心**：三层图记忆：原始轨迹 → 结构化决策路径（状态机）→ 高层策略元认知。用 RL（reinforcement-based weight optimization）估计每条元认知的经验效用，优化后的策略动态注入 LLM 的训练循环。和 causal-memory 的 Q-value Bellman 动态高度对应——都是用 reward feedback 更新记忆权重。
- **对项目的含义**：
  - 继 MemRL/MemQ/DeltaMem/CMI-Mem/AttriMem 之后又一个 RL-based 记忆权重更新
  - 这篇的"三层抽象"（trajectory → decision path → meta-cognition）和我们的三层（chunks → causal_edges → meta_edges）结构对应
  - RL 在记忆管理上的应用正在形成学术共识
- **是否值得深挖**：⭐ 可选
