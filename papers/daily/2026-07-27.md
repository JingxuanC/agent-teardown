## 🔥 必须深挖(3 条)

### 🔥-1 · Anthropic 发布 "Dreaming" —— 官方版的 sleep-time compute

- **来源**:mindstudio.ai/blog/code-with-claude-2026-new-agent-features + lennysnewsletter.com + dotzlaw.com
- **主题**:③ 7×24 / 长时运行 ⑦ 持续学习 / sleep-time compute
- **类型**:产品发布(Code with Claude 2026 开发者大会)
- **核心**:Anthropic 发布了 5 个新特性,其中两个直接命中我们的研究:
  - **Dreaming**:agent 在空闲时"做梦" —— 对应 Letta 的 sleep-time compute([10](../../insights/10-memory-frameworks.md) §4)和 [05](../../insights/05-agi-7x24.md) §3.2 的"睡眠巩固"。
  - **"Infinite" context window**:研究负责人 Diane Penn 原话"context windows that feel infinite" —— 对应 [09](../../insights/09-stateless-function.md) §4 的长上下文墙。
  - **Multi-agent orchestration**:Lead agent + specialist sub-agents + 共享文件系统。
  - **Memory consolidation**:dotzlaw.com 提到"out-of-band memory consolidation" 作为 5 个 primitives 之一。
- **对项目的含义**:
  - **验证 [05](../../insights/05-agi-7x24.md) §3.2** —— Anthropic 自己做了 sleep-time(他们叫 Dreaming),说明这条路线是对的
  - **挑战 [09](../../insights/09-stateless-function.md) §4 三堵墙** —— "infinite context" 如果真的实现了,会推翻长上下文墙的假设。需要验证是真无限还是 marketing
  - **causal-memory 的定位变了** —— 如果 Anthropic 自己做 memory consolidation,Dreaming 可能会内置某种记忆整理。causal-memory 需要考虑"如何和 Anthropic 的 Dreaming 互补"而不是"替代"
- **是否值得深挖**:🔥 **必须**。这可能改变 causal-memory 的市场定位。需要深入看 Dreaming 的技术细节(是离线 context 整理?还是真的权重更新?)

### 🔥-2 · Mem0 新算法 LongMemEval 达到 93.4 分(+25.6 提升)

- **来源**:mem0.ai/blog/state-of-ai-agent-memory-2026 + mem0.ai/blog/how-to-test-ai-agent-memory
- **主题**:① Agent 记忆 ⑤ 因果推理(多跳)
- **类型**:benchmark 报告
- **核心数据**:
  - Mem0 新算法在 LongMemEval 上达到 **93.4 分**(比旧算法 +25.6)
  - **最大提升**:temporal reasoning **+29.6 分**,multi-hop **+23.1 分**
  - 改进来自"如何发现和打分记忆",不是"塞更多 token"
- **对项目的含义**:
  - **直接挑战 causal-memory 的差异化** —— [10](../../insights/10-memory-frameworks.md) §3 用 LongMemEval 证明 Zep 比 Mem0 高 15 分。现在 Mem0 自己追上来了(93.4 vs Zep 的 63.8),**而且多跳提升了 23 分** —— 这正是 trace_cause_chain 的领域
  - **causal-memory 的 benchmark 需要重跑** —— [papers/daily/2026-07-26.md](2026-07-26.md) 的 LongMemEval 对比数据已经过时
  - **需要重新评估**:如果 Mem0 用 timestamp-aware + multi-hop 就能达到 93.4,causal-memory 的因果图还有多少额外价值?
- **是否值得深挖**:🔥 **必须**。这可能是 causal-memory 差异化论点的最大挑战。需要看 Mem0 新算法的具体实现(timestamp-aware resolution 是什么?)

### 🔥-3 · "Graph as Agent Memory" 双路线综述 + Mnemis 双系统检索

- **来源**:vadim.blog/knowledge-graph-agent-memory/ + arXiv:2602.05665 + arXiv:2602.06052
- **主题**:① Agent 记忆 ④ 重构式记忆
- **类型**:博客深度分析 + 两篇综述论文
- **核心**:
  - 2026 年两篇大型综述(arXiv:2602.05665 和 2602.06052)把图重新定义为"agent memory 的基底"
  - **Mnemis**(arXiv:2602.15313)提出**双系统检索**:System-1 快速相似度 → System-2 结构化多跳遍历
  - **Engram**(arXiv:2606.09900)提出 **bi-temporal memory engine**(和 Zep 的 valid_from/valid_to 类似,但更激进)
  - Graph-based agent memory 的"四阶段生命周期":ingest → structure → retrieve → evolve
- **对项目的含义**:
  - **验证 [10](../../insights/10-memory-frameworks.md)** —— 图记忆赛道在 2026 年正式成为主流研究方向(两篇综述 + 多个新系统)
  - **挑战 causal-memory 的独特性** —— 如果图记忆已经成为共识,causal-memory 需要更明确地说"我们不是又一个图记忆系统,我们专门存因果边"
  - **Engram 的 bi-temporal** 直接对应我们 v0.6 加的 valid_to 字段 —— 说明时序窗口是行业共识
  - **Mnemis 的 System-1/System-2 双路检索** 对应 [13](../../insights/13-reconstructive-memory.md) §2 的重构式方向
- **是否值得深挖**:🔥 **必须**。这是图记忆赛道的最新全景图,需要和 causal-memory 做定位对比
