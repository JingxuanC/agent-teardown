## 🔥 必须深挖(3 条)

### 🔥-1 · Hippo：Rust 海马体记忆系统——架构高度重叠

- **来源**：github.com/kitfunso/hippo-memory
- **主题**：① Agent 记忆 ③ 7×24
- **核心**：Hippo 是一个 Rust 实现的 agent 记忆系统，模拟海马体：
  - **三层记忆**：Buffer → Episodic → Semantic（对应我们的 chunks → causal_edges → meta_edges）
  - **Sleep consolidation**：`hippo sleep` 命令触发巩固——3+ 相关 episodic 合并成 1 个 semantic，原始 episodic 衰减
  - **Outcome feedback**：`hippo outcome --good/--bad` 调整 reward factor，影响 half-life（正面 → 衰减变慢，负面 → 衰减加快）
  - **Active forgetting**：30 天未被检索的记忆自动标记为 stale
  - **Decay**：half-life 衰减（默认 14 天），half_life 会因检索延长
- **和 causal-memory 的重叠**：
  - ✅ 海马体三层（高度重叠）
  - ✅ Sleep consolidation（和 SWR 对应）
  - ✅ Outcome feedback（和 Q-value 对应）
  - ✅ Active forgetting（和 GC/LTD 对应）
  - ❌ **无因果关系类型**——Hippo 的记忆是 valence (good/bad/error)，不是 caused/prevented
  - ❌ **无 prevented 负扩散**——Hippo 的 negative 只是加速衰减，不是负向传播
  - ❌ **无 spreading activation**——Hippo 用 half-life + retrieval_count 排序，不做图传播
  - ❌ **无前向模拟**——Hippo 没有 intervention_query
- **对项目的含义**：Hippo 验证了海马体架构 + sleep consolidation + outcome feedback 的工程可行性，但这些我们都有。差异化仍然在因果关系类型 + prevented 负扩散 + 前向模拟。Hippo 是"海马体架构"的竞品，但不是"因果记忆"的竞品。
- **是否值得深挖**：🔥 **必须**

### 🔥-2 · Vestige：Rust MCP 记忆 server——技术栈几乎相同

- **来源**：github.com/samvallad33/vestige
- **主题**：① Agent 记忆
- **核心**：Vestige 是一个 Rust MCP 记忆 server，和 causal-memory 的技术栈几乎相同：
  - **FSRS-6 spaced repetition**——间隔重复算法控制记忆衰减
  - **Prediction-error gating**——只在预测和实际不符时写入（类似 Nemori 的 prediction gap）
  - **Active forgetting**——主动遗忘不用的记忆
  - **Spreading activation**——图传播检索
  - **3D memory dashboard**——可视化记忆状态
  - 支持 Claude Code / Cursor / VS Code / Codex / Windsurf
- **和 causal-memory 的重叠**：
  - ✅ Rust + MCP server（技术栈完全相同）
  - ✅ Spreading activation（核心机制重叠）
  - ✅ Active forgetting（和 GC 对应）
  - ✅ Prediction-error gating（和 novelty entropy 对应，但 Vestige 用 FSRS-6 更成熟）
  - ❌ **无因果关系类型**
  - ❌ **无 prevented 负扩散**
  - ❌ **无海马体分层**（Vestige 是扁平的）
  - ❌ **无前向模拟**
- **对项目的含义**：Vestige 是技术栈最接近的竞品——Rust + MCP + spreading activation + active forgetting。但 Vestige 没有因果维度。**在"记忆工程"维度我们不再独特——Rust+MCP+spreading activation 正在成为标配。独特性完全押在因果关系 + prevented 负扩散 + 前向模拟上。**
- **是否值得深挖**：🔥 **必须**

### 🔥-3 · Cognitive Capability Gaps Taxonomy（arXiv:2608.02553）

- **来源**：arXiv:2608.02553 · "A Taxonomy of Cognitive Capability Gaps in Generative and Agentic AI"
- **主题**：① Agent 记忆 ② 因果推理 ⑦ 持续学习
- **核心**：论文提出了 AI 认知能力的五维分类法，明确引用了 "LLM agents with episodic-semantic memory via spreading activation"（引用 [36] 指向 HeLa-Mem）作为核心认知能力。五个维度：persistent memory / adaptive behavior / cognitive consistency / task autonomy / uncertainty management。
- **对项目的含义**：
  - spreading activation 被正式列为 AI 认知能力的核心组件——验证方向
  - persistent memory 和 adaptive behavior 直接对应 causal-memory 的设计目标
  - 论文的"recommended architecture for cognitive AI"值得参考
- **是否值得深挖**：⭐ 可选

## 元反思

**问题一(先搜再写)**：✅ 全部真实搜索。Hippo 和 Vestige 都有 GitHub README + 代码

**问题二(找替代方案)**：Hippo 和 Vestige 是**直接竞品** —— 技术栈（Rust + MCP）、核心机制（spreading activation + active forgetting + sleep consolidation）高度重叠。但它们都没有因果关系类型。causal-memory 的定位必须从"海马体记忆引擎"收窄到"因果记忆引擎"——"海马体"不再是差异化，"因果"才是

**问题三(跨域类比)**：Hippo 的 outcome feedback（正面 → 衰减变慢，负面 → 衰减加快）对应人脑的**多巴胺奖赏系统**——成功的记忆被强化（LTP），失败的记忆被弱化（LTD）。causal-memory 的 Q-value 是同一机制，但 Hippo 的实现更简洁（reward factor 直接调整 half-life）
