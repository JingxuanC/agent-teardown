## 🔥 必须深挖(4 条)

### 🔥-1 · Nemori：Free Energy Principle 驱动的 surprise-gated 记忆准入

- **来源**：arXiv:2508.03341 · "Nemori: Self-Organizing Agent Memory Inspired by Cognitive Science"
- **主题**：① Agent 记忆 ② 因果推理 ⑦ 持续学习
- **类型**：学术论文（preprint，已有详细实验数据）
- **核心**：Nemori 用 Friston 的 **Free Energy Principle** 做 proactive learning —— 不是被动抽取每条对话，而是只在 **prediction gap**（agent 预测和现实的差距）超过阈值时才写入语义记忆。两个核心原则：
  1. **Configurable Granularity**（可配置粒度）—— 记忆提取的 confidence threshold `f_θ` 可调，适应不同场景
  2. **Predict-Calibrate Principle**（预测-校准原则）—— agent 先预测用户会说什么，当实际消息和预测差距大（surprise）时，才提取这条消息中的新知识写入 DB
- **实验结果**（LoCoMo + LongMemEval）：
  | 系统 | Overall | Short | Long |
  |------|---------|-------|------|
  | RAG | 0.237-0.326 | 0.135-0.222 | 0.117-0.186 |
  | **Nemori** | **0.710-0.821** | **0.466-0.588** | **0.385-0.515** |
  | LangMem | 0.513 | — | — |
  | Zep | 0.585 | — | — |

  Nemori 在 LoCoMo 上达到 **71-82%**，比 LangMem (51%) 和 Zep (58%) 高出 13-29pp。而且 token 消耗仅 3,053ms 延迟（vs Zep 23,255ms）。
- **和 causal-memory 的重叠**：
  - ✅ **Surprise/novelty 触发写入** —— 我们有 novelty entropy trigger，Nemori 有 prediction gap。概念完全对应
  - ✅ **选择性写入** —— 不是所有对话都写入，只写"值得记住的"
- **causal-memory 仍然独有的**：
  - ✅ **因果关系类型**（caused/enabled/prevented）—— Nemori 的记忆是 semantic memory，没有因果语义
  - ✅ **Prevented 负扩散** —— Nemori 没有 spreading activation，更没有负扩散
  - ✅ **SWR 巩固** —— Nemori 是实时写入（gap 出现就写），没有 offline consolidation
  - ✅ **CSR 稀疏矩阵** —— Nemori 用 DB 存储
- **对项目的含义**：
  - **Nemori 的 prediction gap 和我们的 novelty entropy 本质相同** —— 都是"惊讶度"驱动的写入门控。但 Nemori 用的是 Free Energy Principle 的理论框架，比我们的 Shannon entropy 更有理论基础
  - **Nemori 的 LoCoMo 71-82% vs 我们的 67.4%** —— 差距 4-15pp，但他们的 prediction 需要额外的 LLM 调用（先预测再比较），我们的 entropy 计算更轻量
  - **需要考虑用 prediction gap 替代或增强 entropy trigger** —— prediction gap 有更强的理论支撑（FEP），而且能捕捉语义层面的惊讶（entropy 只捕捉词频层面的惊讶）
- **是否值得深挖**：🔥 **必须**。Nemori 的 Predict-Calibrate 原则直接影响我们的写入门控设计

### 🔥-2 · RecMem：Recurrence-based 记忆巩固，省 87% Token（ACL 2026 Findings）

- **来源**：arXiv:2605.16045 · ACL 2026 Findings · github.com/CaiusDai/RecMem
- **主题**：① Agent 记忆 ③ 7×24 ⑦ 持续学习
- **类型**：顶会论文（ACL 2026 Findings）
- **核心**：RecMem 挑战了"eager consolidation"范式（每条消息都调 LLM 提取记忆），提出 **recurrence-based consolidation**：
  1. **Subconscious memory layer**（潜意识层）—— 所有原始交互先用 lightweight embedding 编码存储（不调 LLM）
  2. **Recurrence detection**（递归检测）—— 只有当**语义相似的交互持续递归出现**时，才触发 LLM consolidation
  3. **Semantic refinement**（语义精炼）—— 巩固后用额外机制恢复被丢失的细粒度事实
- **实验结果**：
  - Token 成本降低 **最高 87%**（vs Mem0/Zep/A-MEM）
  - 准确率**超过**所有 SOTA memory 系统
  - 三层架构：subconscious → episodic → semantic
- **和 causal-memory 的重叠**：
  - ✅ **多层记忆** —— RecMem 三层（subconscious/episodic/semantic），我们三层（session_logs/chunks/causal_distilled）
  - ✅ **延迟巩固** —— RecMem 的"recurrence-triggered"和我们的"SWR offline consolidation"都是不急着巩固
- **causal-memory 仍然独有的**：
  - ✅ **因果关系类型** —— RecMem 的 episodic/semantic 没有 caused/prevented 语义
  - ✅ **Spreading activation + 负扩散** —— RecMem 是纯检索，没有图传播
- **对项目的含义**：
  - **RecMem 的 recurrence detection 对我们的 session_logs → distill 管道有直接启发** —— 我们现在是 sequential distill（每个 session 都 distill），可以改成 recurrence-triggered（只在话题重复出现时才 distill），大幅减少 LLM 调用
  - **RecMem 的 87% token 节省是一个强信号** —— eager consolidation 在长周期 agent 中不可持续
- **是否值得深挖**：🔥 **必须**。RecMem 的 recurrence-based consolidation 直接优化我们的 distill 管道效率

### 🔥-3 · Rate-Distortion View：记忆压缩的统一理论框架

- **来源**：arXiv:2607.08032 · "What to Keep, What to Forget: A Rate–Distortion View of Memory Compaction in LLMs and Agents"
- **主题**：① Agent 记忆 ④ 重构式 vs 检索式 ⑥ 长上下文
- **类型**：学术论文（survey + theory）
- **核心**：这篇论文把 KV cache 压缩、prompt 压缩、architectural memory、agent memory 四个层面统一为一个 **rate-distortion problem**：
  - **核心公式**：`I(Y;Ŷ) ≤ min(I(Q;Z), B)` —— 信息瓶颈（Information Bottleneck）形式
  - **跨层下界**：在任何 budget B 下，所有层（KV/prompt/arch/agent）的误差下界由同一个表达式决定
  - **关键洞察**：
    1. **可逆性比任何评分技巧都重要** —— 能取回被丢弃信息的系统，在同等 budget 下始终胜过不能取回的
    2. **Query-agnostic compaction 有可量化的惩罚** —— 在看到 query 前就决定保留什么，会丢掉 query 需要的信息
    3. **重复压缩几乎从未被测量** —— agent 反复压缩同一段记忆，但没有 benchmark 测这个累积损失
- **和 causal-memory 的关系**：
  - **为我们的"raw turns in session_logs, not chunks"设计提供了理论支撑** —— session_logs 保持原始信息（可逆），chunks 是压缩后不可逆的。Rate-Distortion 理论说"可逆 > 不可逆"
  - **我们的 SWR consolidation 应该产出新图而非修改原图** —— 这正是 Anthropic Dreams API 的设计，也符合 rate-distortion 的可逆性原则
- **对项目的含义**：
  - **这篇论文给了我们一个框架来量化 causal-memory 的压缩损失** —— 我们可以测量 SWR consolidation 前后的 information retention
  - **重复压缩的累积损失是一个未被测量的风险** —— 我们的 causal_memory 在长期运行中会反复 consolidate，需要 benchmark 测这个
- **是否值得深挖**：🔥 **必须**。Rate-Distortion 是记忆系统的理论地基，causal-memory 的所有设计决策都可以用这个框架评估

### 🔥-4 · CMI-Mem：CMI-Augmented RL 做可泛化的长期记忆管理

- **来源**：arXiv:2607.20553 · "CMI-Mem: Toward Generalizable Long-Term Memory Management via CMI-Augmented Reinforcement Learning"
- **主题**：① Agent 记忆 ⑦ 持续学习
- **类型**：学术论文（preprint）
- **核心**：CMI-Mem 用 Conditional Mutual Information (CMI) augmented RL 来学习记忆管理策略：
  - 不同于 Memory-R1 / DeltaMem 的纯 RL（从下游 reward 学习），CMI-Mem 在 RL reward 中加入 CMI 项 —— 衡量记忆操作（ADD/UPDATE/DELETE）对任务的条件互信息
  - 目标是**可泛化**（generalizable）—— 不只在训练分布上工作，还能迁移到新任务
- **和 causal-memory 的关系**：
  - 继 MemRL/MemQ/DeltaMem 之后，又一个新的 RL-based 记忆管理方法
  - CMI 的"哪些记忆对任务有信息增益"和我们的 Q-value 更新（记忆的有用性反馈）概念类似
- **对项目的含义**：
  - RL-based 记忆管理正在形成学术共识（MemRL + MemQ + DeltaMem + CMI-Mem + AgeMem）
  - causal-memory 的静态 confidence → 动态 Q 值升级方向正确，但需要考虑 CMI 作为 reward signal
- **是否值得深挖**：⭐ 可选。CMI 的理论值得了解，但优先级低于 Nemori 和 RecMem

## ⭐ 值得关注(3 条)

### ⭐-1 · LightMem：Atkinson-Shiffrin 三阶段记忆 + Sleep-time 巩固

- **来源**：arXiv:2510.18866 · "LightMem: Lightweight and Efficient Memory-Augmented Generation"
- **核心**：LightMem 用 Atkinson-Shiffrin 人类记忆模型（感觉记忆 → 短期记忆 → 长期记忆）组织成三个阶段，长期记忆用 sleep-time update 做 offline 巩固
- **对项目的含义**：验证 sleep-time consolidation 方向。LightMem 的三阶段和我们的三层（session_logs/chunks/causal_distilled）对应

### ⭐-2 · ZenBrain：神经科学启发的 7 层记忆架构

- **来源**：arXiv:2604.23878 · "ZenBrain: A Neuroscience-Inspired 7-Layer Memory Architecture for Autonomous AI Systems"
- **核心**：7 层记忆架构，明确引用了 LightMem、A-MEM 等并发系统
- **对项目的含义**：又一个神经科学启发的多层记忆系统。7 层可能过度设计，但可以参考其分层逻辑

### ⭐-3 · SCM (Sleep-Consolidated Memory)：算法性遗忘

- **来源**：arXiv:2604.20943 · "Sleep-Consolidated Memory with Algorithmic Forgetting"
- **核心**：sleep-consolidated memory + algorithmic forgetting —— 在巩固时主动遗忘不重要信息
- **对项目的含义**：和我们的 SWR 中的 GC (Garbage Collection) 机制对应。SCM 的"算法性遗忘"可以启发我们的 GC 策略
