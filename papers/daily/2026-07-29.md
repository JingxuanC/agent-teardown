### 🔥-1 · MCP 2026-07-28 大改:删掉 initialize 握手,变成无状态协议

- **来源**:blog.modelcontextprotocol.io + workos.com + 多篇分析
- **主题**:② Agent 框架(MCP 协议)
- **类型**:协议规范发布(MCP 2.0)
- **核心**:MCP 7 月 28 日发布了"自发布以来最大的修订":
  - **删除 `initialize`/`initialized` 握手**(SEP-2575)
  - **删除 `Mcp-Session-Id`**(SEP-2567)—— 任何请求可以落在任何服务器实例上
  - 协议变成**完全无状态** —— 每个请求自包含
  - 但每个请求大了 118%(从 190 bytes 到 414 bytes,因为要带更多元数据)
  - 新增 `server/discover` 方法替代初始化握手
  - 引入 `MCP-Protocol-Version` header 和扩展框架
- **对项目的含义**:
  - **直接影响 causal-memory 的 MCP server** —— causal-memory 用的是 `rmcp` crate 的 `initialize` + `serve` 流程,PR #5 修的就是这个。MCP 2.0 后**握手不存在了**,`server.waiting()` 修复可能不再需要(因为没有 init 要等)
  - **验证 [09](../../insights/09-stateless-function.md) 的核心命题** —— MCP 自己也变成了无状态协议!这和"LLM 是无状态函数"([09](../../insights/09-stateless-function.md) §1)完全对齐 —— 不仅 LLM 是无状态的,连接 LLM 的协议也是无状态的
  - **causal-memory 需要跟进 MCP 2.0** —— 等 `rmcp` crate 更新支持新协议后,需要适配
- **是否值得深挖**:🔥 **必须**。这是基础设施层面的变更,影响所有 MCP server

### 🔥-2 · MemRL: 运行时强化学习让 agent 从记忆中自演化

- **来源**:arXiv:2601.03192 + datasciocean.com + medium 分析
- **主题**:① Agent 记忆 ⑦ 持续学习
- **类型**:论文(2026-01,近期被大量引用)
- **核心**:MemRL 提出了一个**不改模型权重的运行时学习**框架:
  - **Model-Memory 解耦**:LLM 冻结,学习发生在记忆层
  - **Intent-Experience-Utility 三元组**:每条记忆有意图(z)、经验(e)、效用值(Q)
  - **Q-Learning 式更新**:`Q_new ← Q_old + α(r - Q_old)` —— 成功的经验 Q 值升高,失败的降低
  - **失败的 Q_init = 0**(不是负数)—— "对失败的反思本身有价值"
  - 在 ALFWorld 上比 MemP 提升 56%,HLE benchmark 上 CSR 达 61.3%
- **对项目的含义**:
  - **直接补全 [12](../../insights/12-generativity.md) §4 的"生成性能改善吗"** —— MemRL 给出了答案:**不改权重,通过记忆的 Q 值更新实现持续学习**
  - **causal-memory 应该加 Q 值** —— causal-memory 的 confidence 是静态的(写入时定),MemRL 的 Q 值是**动态更新的**(根据使用结果)。causal-memory 的 `halflife_hours`(v0.4 路线图)可以升级为 MemRL 式的 Q 值
  - **"对失败的反思本身有价值"(Q_init=0)** —— 这对应 causal-memory 的 `trace_cause`(失败归因)。MemRL 证明了失败经验不应该被惩罚(Q 不设为负数),应该被保留以待未来参考
- **是否值得深挖**:🔥 **必须**。这是 [12](../../insights/12-generativity.md) 生成性问题的最佳学术答案

### 🔥-3 · SCM: 睡眠巩固记忆 + 算法遗忘(NREM/REM 双阶段)

- **来源**:arXiv:2604.20943 + emergentmind.com + ogham-mcp.dev 谱系分析
- **主题**:① Agent 记忆 ③ 7×24 ⑦ 持续学习
- **类型**:论文(2026-04)
- **核心**:SCM 实现了五个受神经科学启发的组件:
  - **有限容量工作记忆**(Miller's 7±2)
  - **多维重要性标注**
  - **离线睡眠巩固**(分 NREM 和 REM 两阶段)
  - **基于价值的主动遗忘**(90.9% 噪音移除率)
  - **计算自模型**(内省能力)
  - 8/8 benchmark 全过,搜索延迟 <1ms 即使 360 个概念
- **对项目的含义**:
  - **直接验证 [05](../../insights/05-agi-7x24.md) §3.2 的"睡眠巩固"** —— SCM 用 NREM(巩固) + REM(重组) 两阶段实现了 [05](../../insights/05-agi-7x24.md) 预测的"16h 工作 + 4h 睡眠 + 4h 深度巩固"
  - **"主动遗忘"是 causal-memory 缺的** —— causal-memory 目前只加不删(除非手工 valid_to)。SCM 的"90.9% 噪音移除"说明遗忘是记忆系统的核心能力,不是可选功能
  - **NREM/REM 双阶段** 对应 Vela 的 Reflector 和 Claude Code 的 Dream,但 SCM 更精确 —— NREM 做"保留重要的,移除噪音",REM 做"重组和关联"
- **是否值得深挖**:🔥 **必须**。这是目前最完整的"睡眠巩固"学术实现
