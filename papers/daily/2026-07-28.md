## 🔥 必须深挖(3 条)

### 🔥-1 · Letta "Filesystem is All You Need" —— 74% LoCoMo 用纯文件系统

- **来源**:letta.com/blog/benchmarking-ai-agent-memory + 多篇博客引用
- **主题**:① Agent 记忆 ④ 重构式 vs 检索式
- **类型**:benchmark 报告 + 博客
- **核心**:Letta 发了一篇博客 "Benchmarking AI Agent Memory: Is a Filesystem All You Need?" —— 一个简单的 agent 用**纯文件系统存储**对话历史(无向量库、无知识图谱、无 SQLite),在 LoCoMo benchmark 上达到 **74.0%**。这比 Zep 的 Graphiti(63.8%)还高。
- **对项目的含义**:
  - **挑战 [10](../../insights/10-memory-frameworks.md) §3 的 benchmark 排名** —— 之前 Zep > Mem0,但 Letta 的纯文件 > Zep。**复杂的图结构不一定比简单的文件好**
  - **挑战 causal-memory 的差异化论证** —— 如果纯文件都能 74%,causal-memory 的"因果图"到底值多少分?
  - **但有一个反驳**:nicoloboschi.com 的分析指出 "benchmarks are small. In production, you'll hit context rot, multi-hop limitations" —— **benchmark 分数高 ≠ 生产好用**。LoCoMo 的对话量可能不够大,文件系统还没到瓶颈
- **是否值得深挖**:🔥 **必须**。这是对整个记忆框架赛道的一个挑战性发现 —— 简单方案在 benchmark 上可能赢了复杂方案

### 🔥-2 · Memora: 跨周到月级的新 benchmark + "遗忘"评测

- **来源**:arXiv:2604.20006 + github.com/geniesinc/Memora
- **主题**:① Agent 记忆 ③ 7×24
- **类型**:论文 + 开源 benchmark
- **核心**:Memora 是一个新的长期记忆 benchmark,跨**周到月级**的用户对话。它的独特之处是评测**三种记忆能力**:
  - Weekly (W)
  - Monthly (M)
  - Quarterly (Q)
- 而且它不只测"记住了多少",还测"**遗忘**"(From Recall to Forgetting)—— 对应 [05](../../insights/05-agi-7x24.md) 说的"agent 会不会遗忘重要信息"
- **对项目的含义**:
  - **补全 [05](../../insights/05-agi-7x24.md) 的评测空白** —— 之前 LongMemEval 测的是单 session 到多 session,Memora 测的是**周到月级**的跨时间记忆。这正是 7×24 AGI 需要的评测尺度
  - **causal-memory 应该跑 Memora** —— 如果 causal-memory 在 Quarterly 级别表现好(因果边不被 compaction 压掉),这直接证明 [papers/02](../papers/02-compaction-degradation.md) 的论断
- **是否值得深挖**:🔥 **必须**。这是目前唯一测试月级 + 季度级记忆的 benchmark

### 🔥-3 · "记忆赛道正在分裂成三条路线" —— 行业观察

- **来源**:x.com/Soranlan + cloud.tencent.com 分析
- **主题**:① Agent 记忆
- **类型**:行业分析
- **核心**:一篇 Twitter 分析指出 2026 年 agent 记忆赛道正在分裂成三条路线:
  - **路线一:云 API 派**(Mem0)—— 发一句话自动装完,跨设备共享,2 分钟上手
  - **路线二:文件系统派**(Letta/OpenViking)—— 文件即记忆,简单透明,可审计
  - **路线三:图谱派**(Zep/Graphiti)—— 时序知识图谱,精确但复杂
- **对项目的含义**:
  - **causal-memory 是第四条路线**:因果图谱派 —— 不是实体关系图(Zep),不是文件系统(Letta),是**因果边图**
  - 这比之前的定位更清晰 —— 不是"又一个图记忆",是"第四条路线"
- **是否值得深挖**:🔥 写进 causal-memory README 的定位更新

## 对 insights 04-14 的影响

### 被挑战的论点

1. **[10](../../insights/10-memory-frameworks.md) §3 benchmark 排名** —— Letta 纯文件 74% > Zep 63.8%。复杂图结构在 benchmark 上不一定赢简单方案。需要更新对比表
2. **causal-memory 的差异化论证** —— 如果纯文件都 74%,causal-memory 需要更强的理由说明"为什么因果图比文件好"。答案可能是:**benchmark 不测因果**(测的是事实召回),所以 causal-memory 的优势在 benchmark 之外

### 被补全的论点

1. **[05](../../insights/05-agi-7x24.md) 评测空白** —— Memora(周到月级)和 EverMemBench(约束+主动性)补上了之前缺的长期 + 行为维度评测
2. **记忆赛道分化** —— 三条路线(云 API / 文件系统 / 图谱)的观察帮 causal-memory 定位为"第四条路线:因果图谱"

### 没有被印证的(警惕"看起来圆满")

今天最大的发现 🔥-1(Letta 纯文件 74%)是**挑战性的** —— 它暗示复杂的记忆架构(包括 causal-memory 的因果图)在 benchmark 上可能不如简单方案。这需要认真对待。

**跨域类比**:人脑的记忆也不是"存在一个地方" —— 海马体(快速 episodic)+ 新皮层(慢速 semantic)是两个不同系统。Letta 的"纯文件"可能对应海马体式的"原始 episodic 存储" —— 短期够用,但长期需要新皮层式的"结构化提炼"(Zep 的图谱 / causal-memory 的因果边)。**Memora 的 quarterly 级评测可能揭示这一点** —— 文件系统在月级可能开始失效。
